## 一句话定义

**中文**：让序列里的每个位置，按"相关性"对自己以外的位置做加权求和，权重由当前位置的 query 与其他位置的 key 的相似度算出。

**English**: A weighted aggregation over sequence positions, where the weights for each position are computed as the compatibility between its own query vector and the key vectors of other positions.

## 我的理解

把这当成一次**带查询条件的检索**。每个位置提出一个问题（query），库里每个位置挂一张标签（key）+ 一份内容（value）。问出来的问题跟谁最合，谁的内容就多拿一点。跟数据库检索不同的地方是：结果不是取回某一条，而是所有人的内容按匹配度混在一起，所以拿到的一定是"综合印象"，不是"确切原文"。

这也是为什么注意力本身不保证事实准确——它做的是加权平均，加权平均天然会模糊细节。

计算发生在分词（Tokenization，[待写](../roadmap.md)）之后：进来的已经是 token 序列，注意力只处理向量，不知道字面。

## 核心机制

分四步，全部是矩阵运算：

1. **投影**。输入序列 $X$ 分别乘以三个学到的权重矩阵，得到 $Q = XW^Q$、$K = XW^K$、$V = XW^V$。
2. **算分数**。$QK^\top$ 得到每个位置对所有位置的匹配分数。
3. **缩放**。除以 $\sqrt{d_k}$（$d_k$ 是 key 的维度）。作用是防止维度变大时点积方差过大，softmax 被推到饱和区导致梯度消失。
4. **加权求和**。softmax 归一化后乘 $V$，得到输出。

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

**多头**：把维度切成 $h$ 份，各自独立做上面这套，再拼接。作用是让不同头去关注不同关系（有的看邻接词、有的看句法、有的看指代），单头只能学到一种加权方案。

**成本**：序列长度 $n$ 时，$QK^\top$ 是 $n \times n$ 矩阵，时间和显存都是 $O(n^2 d)$。这是 [上下文窗口](context-window.md) 无法无限扩大的根本原因，也是各类线性注意力、稀疏注意力方案的动机。

**因果掩码**：自回归生成时，把"未来位置"的分数置为 $-\infty$，softmax 后即为 0，保证位置 $i$ 只能看到 $i$ 之前的内容。

## 边界：它不是什么

- **与 [Transformer 架构](transformer.md) 的区别**：注意力是一种**运算**，Transformer 是**架构**。Transformer 里还有前馈层、残差连接、层归一化、位置编码；没有这些，光堆注意力跑不起来。把两者当同义词是入门期最常见的混淆。
- **与卷积的区别**：卷积的权重窗口形状固定、位置无关；注意力的权重随输入内容变化、范围全局。所以卷积的归纳偏置更强（小数据更好训），注意力更灵活但更吃数据。
- **与检索（RAG 那种检索）的区别**：检索在外部语料库上做、结果是一次性取回文本；注意力在本次前向的上下文内部做、结果是向量。名字都叫"注意力/注意力分数"，但不在一个层面上。

## 常见误解

1. **注意力权重可以当解释** → 权重高只说明这个位置的 value 对本次输出贡献大，不说明模型"依据"它做决策。已有实验表明改动高权重位置未必改变输出，反之亦然。当调试线索可以，当证据不行。
2. **注意力让模型有全局视野** → 掩码、窗口、训练长度都会限制实际可见范围。理论公式看全局，实际实现常常只看局部。
3. **权重越大越重要** → softmax 强制权重和为 1，某个位置权重高，往往只是因为其他位置被摊薄了，不代表绝对强度。

## 应用场景

- **该用**：需要建模任意两位置之间的长程依赖，且序列长度可控（几百到几千 token）、数据量足够。
- **不该直接用**：序列极长（数万 token 以上）且硬件受限——此时 $O(n^2)$ 是硬约束，要么先做检索/分块，要么换稀疏/线性注意力。
- **超出语言**：只要能把对象编码成集合 + 特征，就能用注意力聚合。视觉 patch、图节点、推荐候选、多模态对齐都在用同一套公式。

## 自测

1. 缩放因子用 $\sqrt{d_k}$ 而不是 $d_k$，如果改成不缩放，训练早期会发生什么？
2. 多头注意力把同样的计算重复 8 次，为什么总计算量没有变成 8 倍？
3. 因果掩码在公式里的位置是 softmax **之前**还是**之后**？换个位置结果差在哪？
