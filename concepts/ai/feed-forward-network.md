## 一句话定义

**中文**：Transformer 块中按位置独立作用的两层全连接网络，中间维度通常扩大数倍再压回原维度。

**English**: A two-layer fully-connected network applied identically and independently to each position in a Transformer block, expanding the hidden dimension and projecting it back.

## 我的理解

注意力负责"位置之间交换信息"，前馈网络负责"对每个位置各自做加工"。

两者分工构成 Transformer 的核心节奏：**先横向混合，再纵向变换。**

参数量上，前馈层占一个块的约三分之二，是整个模型最大的参数池。所以问"模型容量放在哪"，答案主要在这里——这也解释了为什么 MoE（把单个前馈层换成多个专家）成为扩参数量的主要手段。

一个被广泛引用但仍在讨论的解释：前馈层承担事实知识的存储，注意力负责按上下文把这些知识调出来。**宜作为工作假设使用，不要当成已定论。**

## 核心机制

**结构**：线性 → 激活 → 线性。中间维度通常是模型维度的 4 倍（如 4096 → 16384 → 4096）。

**为什么中间要放大再压回**：先把特征映射到更高维空间，让非线性激活可以切分更多模式，再压回原维度。这是经典的"升维—非线性—降维"套路。

**逐位置独立**：同一个前馈层应用到序列的每个位置，**位置之间没有任何交互**。这是它与注意力的根本分工——想清楚这一点，就能理解为什么去掉注意力模型不会跨位置推理，去掉前馈层模型几乎不工作。

**激活函数演进**：ReLU → GELU → SwiGLU 一类门控结构。门控结构在同等算力下通常更高效。

**现代变体 MoE**：把单个前馈层换成多个"专家"加一个路由，每个 token 只激活其中少数。**它省的是计算量，不是参数量**——总参数量反而更大。

## 边界：它不是什么

- **与[注意力](attention-mechanism.md)的区别**：注意力做**位置之间**的信息交换；前馈层做**单个位置内部**的变换。前者是横向的，后者是纵向的。
- **与 MoE 的区别**：MoE 是前馈层的**稀疏化实现**，不是新机制。它改变的只是"用哪部分参数"。
- **与一般全连接层的区别**：这里的全连接层在所有位置上**共享同一组权重**，这是它能处理任意长度序列的原因。

## 常见误解

1. **去掉前馈层影响不大** → 它占参数大头，去掉后模型基本无法工作。
2. **前馈层越大越好** → 需与数据量、模型维度匹配。盲目放大只增加参数，不增加有效容量。
3. **前馈层也在做位置间推理** → 不做。位置间交互只发生在注意力里。
4. **MoE 省显存** → 它省**计算量**（每 token 只走部分专家），但总参数更多，**显存需求更高**。

## 应用场景

- **该关注**：估算参数量与显存占用；理解 MoE 的取舍；判断微调的改动面（全参微调时前馈层是主要开销）
- **判断依据**：需要"扩容"时，先问是缺参数还是缺算力——缺算力用 MoE，缺参数直接加深加宽
