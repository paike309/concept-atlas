## 一句话定义

**中文**：从模型输出的概率分布中选择下一个 token 的规则。模型给出分布，采样决定取哪一个。

**English**: The rule that selects the next token from the probability distribution the model produces — the model proposes a distribution, sampling picks from it.

## 我的理解

这一层容易被忽略，但它直接决定了"同一个模型为什么表现差别那么大"。

模型输出的是**整个词表上的概率分布**，而不是一个词。采样策略是分布与最终文本之间的那道闸门。

关键纠正一个常见说法：**温度不是"随机性旋钮"，它是分布形状的调节器。** 低温让分布更尖锐（高概率项被放大），高温让分布更平坦（低概率项获得机会）。所以高温会让模型**跑题**，而不是"更有创意"——它只是让更多低质选项有机会被选中。

另一个要点：**贪心（每次取最大概率）不等于最好。** 局部最优的下一步会累积成平庸甚至退化的整段，这也是重复循环现象的来源之一。

## 核心机制

| 参数 | 做法 | 特点 |
|---|---|---|
| 温度 T | logits 除以 T 再 softmax | T<1 更确定，T>1 更随机，T=1 保持原分布，T→0 等价贪心 |
| Top-k | 只在概率最高的 k 个候选里采样 | 砍掉长尾，但 k 固定 |
| Top-p（核采样） | 取累积概率达到 p 的最小候选集 | **自适应**：分布尖锐时候选少，平坦时候选多 |
| 重复惩罚 | 对已出现 token 降低概率 | 缓解循环输出 |

**Top-p 相比 Top-k 通常更稳**：分布很尖锐时 top-k 会把大量近乎零概率的候选项放进来，而 top-p 会自动收窄。

**参数与任务要匹配**：

- 事实抽取、代码、结构化输出 → 低温 + 严格截断
- 创意写作 → 较高温 + top-p
- **评测与回归测试 → 必须固定参数**，否则无法区分"改好了"和"运气好"

**与模型能力的区分**：调参数只能在已有分布里挑，**不能创造分布里没有的能力**。

## 边界：它不是什么

- **与训练的区别**：采样只在推理期起作用，不改权重。
- **与[提示工程](prompt-engineering.md)的区别**：提示改变分布（输入变了，概率就变了），采样只在给定分布上做选择。两者作用点不同。
- **与随机种子的关系**：设种子可以复现，但不同框架、不同批大小的实现细节会影响结果，**不能保证跨环境一致**。

## 常见误解

1. **温度越高越有创造力** → 它只是让低概率选项（包括错误选项）更容易被选中。
2. **temperature=0 就完全可复现** → 通常更稳定，但并行计算的非确定性仍可能带来差异。
3. **top-p 和 top-k 差不多** → top-p 随分布自适应，通常更稳；top-k 在分布平坦时会截断合理候选。
4. **重复输出一定怪采样参数** → 采样是诱因之一，也可能是上下文或训练目标导致的模式退化。

## 应用场景

- **该做**：按任务定参数并写进配置，不要散落在代码各处；评测与回归测试固定参数；结构化输出用低温
- **判断依据**：比较两版提示词之前先固定温度与 top-p。否则**无法区分是提示变好了还是运气好**
- **该记的**：参数是实验设计的一部分，不是随手旋钮
