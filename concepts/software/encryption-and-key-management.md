## 一句话定义

**中文**：用密码学保护数据在传输与存储中的机密性与完整性，并管理那些"保护数据的密钥"本身。

**English**: Protecting data in transit and at rest with cryptography, and managing the keys that protect that data.

## 我的理解

**加密的失效几乎从不出在算法上，而出在密钥和模式上。**

现实中出事的形态高度集中：密钥被硬编码进代码或配置、同一把密钥用于所有租户、加密了但没保护完整性（密文可被篡改）、随机数源不够随机、历史数据在密钥轮换后变成解不开的孤儿。

由此得出三条原则：

1. **不要自己设计加密方案。** 用经过审查的库与高层构造。密码学的错误**不会在功能测试里暴露**——功能全绿，安全性为零，直到被攻击时才暴露。
2. **加密不是访问控制。** 拿到密钥的人就能解密，所以真正的控制点在**密钥的发放、使用与轮换**上。这也解释了一个常见反直觉：**"数据库已加密"通常防的是"磁盘被拿走"，防不住"应用被攻破"**——因为应用有密钥。
3. **加密必须和密钥版本绑定。** 密文里不带密钥标识，就永远无法安全轮换——只能全量重加密或永久保留旧密钥。

## 核心机制

**先分清三种用途**：传输中加密（TLS）、静态数据加密（存储）、端到端加密（服务端也不可见）。三者的威胁模型不同，需要的机制也不同。

**对称与非对称**：对称（如 AES）用于数据本身；非对称（如 Ed25519 / RSA）用于密钥交换与签名。**非对称慢得多**，所以实际方案通常是"用非对称协商出一把对称密钥"。

**必须用 AEAD**（带关联数据的认证加密，如 AES-GCM / ChaCha20-Poly1305）：它同时提供机密性与完整性。**裸用不带认证的模式（ECB、CBC）会被篡改而无法察觉**——这是最常见的实现级错误之一。

**Nonce / IV 的纪律**：必须来自密码学安全的随机源，且**在同一密钥下不能重复**。以 GCM 为例，nonce 重复会直接泄露密钥流，机密性立刻失效。

**密钥生命周期**：生成 → 分发 → 使用 → **轮换** → 撤销 → 销毁。

| 要求 | 原因 |
|---|---|
| 不进版本库、不进代码、不进日志 | 这三处是最常见的密钥泄露渠道 |
| 密文带密钥版本标识 | 否则无法安全轮换，历史数据解不开 |
| 主密钥用 KMS / HSM 托管，数据密钥用信封加密 | 让主密钥无法以明文形态离开受控环境 |
| 每个租户 / 用途独立密钥 | 一把密钥泄露时缩小影响范围 |

**密码要用慢哈希，不要用加密**：密码的校验目标是"比对"，不需要可逆；用可逆加密存密码，等于一旦密钥泄露就全量泄露明文。

**TLS 的实践要点**：证书校验不能关（关闭校验是经典事故）、设定最低协议版本、HSTS、**内部服务之间也要加密**（内网明文是横向移动的加速器）。

## 边界：它不是什么

- **与哈希的区别**：哈希单向（存密码、校验完整性），加密双向（需要还原原文）。**存密码用哈希，不用加密；做完整性校验用哈希或 MAC，不用加密。**
- **与访问控制的区别**：加密保护"数据被拿到"这一情形，访问控制保护"谁可以拿"。两者互补——**只做其中一个都是半套**。
- **与编码 / 混淆的区别**：Base64 不是加密，它没有密钥，任何人都能还原。混淆只是增加阅读难度，同样没有密钥。
- **与"安全删除"的区别**：删了密文不等于删了密钥；只要密钥还在，备份里的密文仍可解。**密钥销毁才是真正的销毁手段。**

## 常见误解

1. **Base64 或自定义编码就算加密** → 没有密钥，等于明文。
2. **自己设计加密算法或"加盐混淆"** → 自研方案通常连已知攻击都挡不住。
3. **只要机密性就够了** → 缺少完整性保护时，密文可被篡改，接收方无法察觉。
4. **密钥可以放在配置里** → 配置会进版本库、被导出、被日志记录。
5. **全盘加密就等于数据安全** → 运行中的应用持有并自动解密，防不住应用层被攻破。
6. **加密了就不用管权限** → 见「边界」，这是两件事。

## 应用场景

- **该做**：传输（TLS）、敏感字段存储（PII、凭据、支付信息）、备份加密
- **判断依据**：问两个问题——"**这个数据如果被别人拿到，损失是什么**"（需要防"被拿走"→ 加密）、"**谁应该能访问它，这个判定在哪一行代码**"（需要防"被访问"→ 访问控制）。两个答案通常都存在
- **配套**：密钥轮换计划、密文带版本、密钥操作纳入[可观测性](observability.md)（谁在什么时候取用了哪把密钥），且**加密密钥的获取路径本身要最小权限**
